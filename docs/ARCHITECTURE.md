## Loading books and levels

All data goes through `js/utils/dataLoader.js`:

- `loadBooks()` reads `data/books.json` as the base and fallback. When
  `useApiBooks` is on, it also requests each tag from the API (see
  [Configuration](CONFIGURATION.md#real-books-from-the-api)), sending the
  `X-API-Key` header.
- `loadLevels()` reads `data/levels.json`.
- `getLevelWithBooks(level)` turns a level's book ids into full book objects.

`js/utils/apiBooks.js` maps API books to the shape the game needs: `title`,
`author`, `genre`, `year`, `size`, `color`, `pages`. The merge keeps the local
ids so existing levels still resolve: real API books replace the first local
entries and the rest stay as fallback.

The **Books** screen (`BooksScene`) uses the same `loadBooks()` data, filtered
by the tags in `bookTags`, with search and pagination.

## Sorting rules

`js/utils/rules.js` maps each level's `rule` string (e.g. `title_az`,
`author_az`, `genre_az`, `year_asc`, `genre_then_title`) to an ordered list of
sort keys. `getExpectedOrder()` produces the correct order, and
`evaluateOrder()` compares the player's left-to-right arrangement against it.
It returns which slots are correct and a `solved` flag.

To add a rule:

1. Add an entry to `RULES` in `rules.js` with a `label` and ordered `keys`.
2. If it sorts by a new book field, add a `KEY_EXTRACTORS` entry.
3. Use the rule name in a level in `data/levels.json`.

## Progress and saving

`js/utils/storage.js` saves to `localStorage`:

- `maxLevelUnlocked`: highest unlocked level (drives **Continue** and the
  level locks).
- `bestScores`: best `{ score, timeMs, moves }` per level, shown in Level Select
  and on the results screen.
- `guestProfile`: anonymous local profile (`id`, `createdAt`, `lastSeenAt`,
  `mode`).
- `globalStats`: totals such as completed levels, completions, moves and play
  time.

## Languages

**Settings** in the main menu switches between English and Spanish. The choice
is saved in `localStorage` and applies to every menu and the in-game HUD.

- UI strings live in `js/utils/i18n.js`. To add a language, add an entry to
  `STRINGS` and to `I18n.available`.
- Level text (title, description, hint) is translated with `_<lang>` fields in
  `data/levels.json` (e.g. `description_es`). `I18n.pick()` resolves them and
  falls back to the base field.
- Book data (titles, authors, genres) isn't translated: it's catalogue content.

## Art, audio and PWA

The librarian frames (`idle`, `happy`, `thinking`) are PNGs in `assets/images/`,
packed into a sprite sheet in `BootScene`. The win spark is
`assets/images/spark.svg`. If a file fails to load, `BootScene` draws simple
procedural textures so the game can still start.

Book spines and the room (wood planks, distant shelves, shelf lips) are drawn in
`js/utils/libraryArt.js`: cloth/leather grain, gold foil marks by genre and a
unique texture per book. The colour stays the spine fill, so the colour rule
still works.

Sounds live in `assets/audio/` (`ui.wav`, `drop.wav`, `win.wav` and a quiet
looping `ambience.wav`) and can be muted from **Settings**. The first tap
unlocks playback (browser autoplay rules). To regenerate the WAVs, run
`node scripts/generate-sfx.mjs`.

`manifest.json`, `sw.js` and `assets/icons/` make the game installable. The
service worker isn't registered during e2e tests (`?test`).
